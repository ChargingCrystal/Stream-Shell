SUPPORTED PERSONAL DISPLAY TARGETS
----------------------------------
- Wide: 32:9 desktop / docked desktop-style use.
- Compact: 16:10 laptop.
- Compact: 16:9 single-screen / temporary laptop use.
- No general-purpose arbitrary-resolution support matrix.
- 21:9 and other additional aspect ratios stay unsupported unless a real personal use case appears.


RULED OUT
---------
- Expanded session restore beyond existing persistent extension storage.
- Mini command palette.
- Global playback hotkeys; external hardware/software already owns that job.
- Separate playback profiles; persistent per-provider settings already cover the use case.
- Picture-in-Shell / compact floating player.
- Automatic inactive-provider window/tab cleanup; reload latency is not worth the resource win with only five core providers.
- Watchlist rules / archive automation; provider histories already cover long-term viewing history.
- Capability-driven buttons in Now Playing.
- Crunchyroll custom subtitle styling / Subtitle Anarchy unless Crunchyroll changes its rendering model.
- Separate provider-availability subsystem; Search/Watchlist already resolve and mark providers.
- Generic responsive support for arbitrary resolutions.
- 21:9 support purely for completeness.


ARCHITECTURE GUARDRAILS
-----------------------
- Shared Home/media data stays single-source. Do not fork separate Compact copies of Watchlist/Search/Continue/Recent/Direct/Subscriptions logic.
- Provider-specific DOM/player behavior belongs behind the dedicated provider adapters.
- Provider API surface grows only for real shared-shell consumers.
- Netflix playback writes must use the MAIN-world bridge / Netflix player API; do not fall back to direct video.currentTime/play()/pause()/rate/volume mutations.
- Keep provider windows warm/minimized for fast switching; do not auto-close/reload inactive providers as a resource strategy.
- Native titlebar trust comes from explicit extension intent/claims. Native geometry, process, focus or taskbar observations may validate/reconcile a claim but must not independently promote normal Opera windows into Stream Shell.
- Unknown display layouts may receive a best-effort fallback, but they are not support targets.
