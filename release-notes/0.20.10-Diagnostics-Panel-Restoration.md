# v0.20.10 – Diagnostics Panel Restoration

The runtime/deep split remains. Opening Diagnostics now paints useful cached information immediately; one bounded active-provider live probe may enrich the panel after it is already responsive. Native Twitch claims, recent provider API self-test reports, display, native sync, and IPC counters are visible without heavyweight browser-wide calls.

* Runtime JSON = cached health and events (no live probes).
* Diagnostics panel = cached health + optional one-shot active-provider content query, no continuous polling.
* Deep JSON = explicit, expensive full checks.

The new cache data is not a substitute for an up-to-date HWND/browser/renderer verification; unknown results are labeled appropriately.
