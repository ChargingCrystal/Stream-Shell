# Stream Shell 0.19.7 — Twitch Persistent Playback & Control Consolidation

- Twitch Workspace streams that were playing stay playing while Dashboard/Discord or another desktop window covers them.
- User-paused Twitch playback is not force-resumed.
- Landing now exposes one Discord-sized Twitch button; Drops/Workspace split controls are removed.
- Unified Remote v0.9.0 changes Auxiliary to Discord 50% / Twitch 50% and removes the Drops button.
- No Twitch geometry/schema migration and no native-helper reinstall are required.
