# v0.20.8 – Emergency IPC Backpressure

- Wide focus/resize uses storage-onChanged in-memory state cache, with no awaited Opera storage, window probes or titlebar claims in hot event path.
- Tab title changes no longer repeatedly re-claim Twitch/native windows; new tab complete remains eligible for claim.
- Runtime diagnostics opens/exports from in-memory counters and last 60 flight events without browser-wide queries or live probes. Optional DEEP export retains explicit full diagnostics and can be slow.
- Flight recorder storage persistence throttled to 5 seconds, 80-event bounded ring.
- No native helper changes, backgrounds/custom artwork excluded from archives.

A 41-second focus reconcile (14.965s storage, 26.229s operations) was observed in v0.20.7; this change eliminates those calls from Wide focus events. Does not guarantee all Opera/Chromium stalls are gone; validate in Windows with WuWa and Twitch.
