# Stream Shell 0.22.24 — Bounded titlebar settings preview

Author: Sven Rieseler

- Keep provider settings columns within the available panel width, including long custom names and large titlebar selections.
- Wrap titlebar preview buttons into continued rows with an ellipsis at the end and start of each continuation. Recalculate rows when the preview width changes.
- Preserve provider order, drag-and-drop and keyboard reordering across rows. Native titlebar behavior is unchanged.

Apply over 0.22.23, reload the extension and reopen Settings. No native reinstall required. No background artwork bundled.
